### Is EvAgent open source?

No. The npm package carries no licence and is reported as UNLICENSED. Treat it as proprietary.

### What does the 20 ms figure refer to?

EvSystem-I, the decision layer EvAgent shares with EvMem, is designed to respond in roughly 20 ms. That is a design target, not a published benchmark.

### Do I need my own API keys?

Yes. Setup asks for an embedding provider and a deriver LLM base URL, API key and model name. EvSphere does not supply these credentials.

### How much disk does setup need?

Around 634 MB for the embedding model, plus the runtime and its Python environment.

### Why is version 0.x?

Interfaces are still moving. Treat behaviour between minor versions as unstable.

### Does it work offline?

Execution is local. Model calls and the embedding download require network access.
